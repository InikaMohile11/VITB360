# VITB360: Student Academic and Performance Hub

## Problem Statement

Students have to keep track of different academic details such as marks, attendance, subjects and overall performance. Managing these details separately can make it difficult to get a clear picture of academic progress.

VITB360 was created as a simple command-line based academic hub that brings these records together in one place. The project started as a basic student-record system and was expanded with features that make the information more useful for students, faculty and administrators.

## Scope of the Project

VITB360 focuses on managing and viewing student academic information. It allows administrators to manage student and subject records, faculty members to enter academic marks and attendance, and students to view their academic performance.

The project uses Python for the application and SQLite for storing student and academic records.

## Target Users

* **Administrator:** Manages student records and subjects.
* **Faculty:** Adds and updates marks and attendance.
* **Student:** Views academic performance, achievements and grade simulations.

## High-Level Features

* Student record management using CRUD operations
* Subject and academic record management
* Role-based access for Administrator, Faculty and Student
* CAT1, CAT2, Term End and Internal marks management
* Attendance management
* Weighted score and grade calculation
* Student performance dashboard
* Achievement Wall
* What-If Grade Simulator
* SQLite database storage
* Command-line interface
